## 2. Цели обработки персональных данных

Обработка персональных данных осуществляется в следующих целях:

- предоставление пользователю сервиса учёта питания на основе анализа фотографий еды;
- авторизация пользователей и обеспечение защищённого доступа к личному аккаунту;
- синхронизация истории сканирований и пользовательских настроек между устройствами;
- улучшение качества AI-моделей анализа изображений на основе обезличенных пользовательских корректировок;
- ответы на обращения пользователей в службу поддержки.

## 3. Правовые основания обработки персональных данных

- Согласие субъекта персональных данных на обработку (пункт 1 части 1 статьи 6 ФЗ-152);
- Исполнение договора, стороной которого является субъект персональных данных (пункт 5 части 1 статьи 6 ФЗ-152) — пользовательское соглашение, размещённое на `myfork.ru/terms`;
- Федеральный закон от 27.07.2006 № 152-ФЗ «О персональных данных».

## 4. Категории субъектов персональных данных

Пользователи мобильного веб-приложения FORK (`myfork.ru`) — физические лица, прошедшие регистрацию или использующие приложение в гостевом режиме.

## 5. Перечень обрабатываемых персональных данных

| Категория | Источник |
|---|---|
| Адрес электронной почты | Указывается пользователем при регистрации |
| Имя пользователя (логин) | Указывается пользователем при регистрации |
| Хеш пароля (bcrypt, не обратимый) | Формируется автоматически при регистрации |
| Фотографии приёмов пищи | Загружаются пользователем добровольно |
| Поведенческие данные о приёмах пищи (ингредиенты, граммы, калории, водный баланс, корректировки) | Сохраняются по действиям пользователя в приложении |
| Профильные данные (отображаемое имя, аватар, рост, вес, пол, год рождения, уровень активности) | Указываются пользователем добровольно в настройках профиля |
| IP-адрес | Фиксируется автоматически при каждом обращении к серверу |
| User-Agent (тип браузера/устройства) | Передаётся браузером пользователя автоматически |
| Идентификатор сессии (cookie) | Формируется автоматически при входе в систему |

Биометрические, специальные категории персональных данных, а также данные несовершеннолетних — **не обрабатываются**.

## 6. Перечень действий с персональными данными

Сбор, запись, систематизация, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передача (предоставление, доступ), обезличивание, блокирование, удаление, уничтожение.

## 7. Способ обработки персональных данных

Обработка осуществляется **с использованием средств автоматизации** (программное обеспечение оператора, размещённое на серверах в Российской Федерации).

## 8. Срок обработки персональных данных

До момента отзыва согласия субъекта персональных данных или до удаления учётной записи пользователем (в приложении предусмотрена функция самостоятельного удаления аккаунта в один клик).

После удаления учётной записи персональные данные удаляются безвозвратно. Обезличенные данные о корректировках AI-анализа могут сохраняться для целей улучшения качества моделей.

## 9. Сведения о трансграничной передаче персональных данных

| Получатель | Страна | Передаваемые данные | Назначение |
|---|---|---|---|
| Anthropic, PBC | США | Фотографии еды + текстовые промпты (без идентификаторов пользователя) | Анализ изображений с помощью моделей Claude |

Передача осуществляется по защищённому каналу (HTTPS/TLS 1.3). Перед передачей фотографии не сопровождаются персональными идентификаторами пользователя (имя, email, IP) — Anthropic получает только изображение и текстовый запрос.

## 10. Меры по обеспечению безопасности персональных данных

| Мера | Реализация |
|---|---|
| Шифрование при передаче | TLS 1.3 на всех соединениях клиент—сервер и сервер—Anthropic |
| Защита паролей | Хеширование bcrypt с солью; пароли в открытом виде не хранятся |
| Управление доступом | Cookie-сессии с флагами HttpOnly, Secure, SameSite=Lax; срок жизни сессии — 30 дней |
| Ограничение запросов | Серверный rate-limiting на эндпоинтах авторизации и анализа |
| Размещение данных | Серверы в Российской Федерации (хостинг Amvera, г. Москва) |
| Резервное копирование | Регулярное резервное копирование базы данных оператором |
| Удаление по запросу | Реализована функция самостоятельного удаления аккаунта пользователем; данные удаляются безвозвратно |

Поскольку оператор обрабатывает персональные данные без использования специальных технических средств защиты информации, требующих сертификации ФСТЭК/ФСБ, и не относится к государственным информационным системам, применяются меры защиты по **4-му (минимальному) уровню защищённости** в соответствии с Постановлением Правительства РФ № 1119.
